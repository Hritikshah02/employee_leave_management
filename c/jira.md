# JIRA Scrum Project: Employee Leave Management (key: ELM)

Create: Projects > Create project > Scrum > Team-managed > Name "Employee Leave Management"

| Story | Priority | Points |
|---|---|---|
| As an employee, I want to apply for leave so that I can take time off. | High | 5 |
| As a manager, I want to approve leave so that requests are processed. | Medium | 3 |
| As an employee, I want to check my leave balance so that I know my remaining days. | Low | 2 |

Steps:
1. Backlog > Create issue > type Story > fill summary, Priority, Story point estimate.
2. Create sprint > drag all 3 stories in > Start sprint.
3. Board: move story 1 to DONE, story 2 to IN PROGRESS, story 3 stays TO DO.
4. Screenshot backlog + board.
